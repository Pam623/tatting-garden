# 梭编花园

少而精的梭编花样，每一个都能逐步跟着编。

网站：<https://pam623.github.io/tatting-garden/>

## 花样怎么存

每个花样是 `patterns/` 里的一个文件，图解由程序根据文件内容画出来，所以图和数字不会对不上。

| 写法 | 意思 |
|---|---|
| `"5"` | 编 5 针 |
| `"o"` | 留一个装饰耳 |
| `"p:last"` | 留一个接耳，取名 `last` |
| `"p:mid+"` | 留一个可以接多次的接耳 |
| `"j:A.last"` | 接到 A 的 `last` 耳 |

后面加标记表示来源：`5?` 是推断，`16~3` 是从照片估算（16 针，上下差 3）。不加表示原图写明。

每个元素是 `ring`（环）或 `bridge`（桥），`flip` 记录它之前是否翻面，相同的元素用同一个 `group`。

新增花样后，把文件名加进 `patterns/index.json`，再运行核对：

```bash
npm test
```

核对只能证明数字彼此一致，不能证明数字正确。

## 信任等级

- **复原稿**：从成品照片推测，还没试编
- **已整理**：从图解转录，有来源
- **已核对**：另一方独立复核过，并通过自动核对
- **已试编**：真的照着编过，确认没问题

产品方案见 [docs/PRD.md](docs/PRD.md)。
